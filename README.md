# ✨ MysticText

> Transforme seu texto com magia e glitter 💖

MysticText é uma ferramenta web para transformar e analisar textos de forma divertida. Cole seu texto, escolha uma transformação e veja a magia acontecer!

---

## 🚀 Funcionalidades

### 🔠 Transformações de texto
| Ferramenta | O que faz |
|---|---|
| MAIÚSCULAS | Deixa todo o texto em maiúsculo |
| minúsculas | Deixa todo o texto em minúsculo |
| Formato título | Primeira letra de cada palavra em maiúsculo |
| AlTeRnAdO | Alterna maiúscula e minúscula em cada letra |
| Inverter texto | Inverte todos os caracteres do texto |
| Remover espaços | Remove espaços duplicados |
| Glitter | Adiciona ✨ entre cada letra |
| Bolha | Converte letras e números em caracteres de bolha |

### 📊 Estatísticas em tempo real
- Contagem de **palavras**
- Contagem de **caracteres**
- Contagem de **frases**

### 🛠️ Outras funções
- **Copiar** o resultado com um clique
- **Limpar** tudo rapidinho
